Tasks that don't lie down and take it.

TasKat is a fast, native task manager with a plugin system and a cat that judges your backlog. No account, no sync server, no bloat — just a config file and a binary.

Rs

Native and fast

Built in Rust from the ground up — starts instantly, stays out of your way, and doesn't eat your battery in the background.

⚙

Plain-text config

Everything about how TasKat behaves lives in one readable config file, so your setup is easy to version, share, or restore.

▤

Plugin system

Extend TasKat instead of waiting for a feature request — drop a plugin in the folder and it's part of your workflow.
