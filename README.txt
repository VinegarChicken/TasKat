Welcome to TasCat!
TasCat is an AI-powered tool that lets you manage your files and folders with simple text commands, right from your File Explorer!

✨ Key Features:
AI-Powered File Management: Use plain English to tell TasCat what you want to do with your files and folders, and it will generate and run the necessary commands.
Right-Click Integration: Access TasCat quickly by right-clicking on any folder (or in the empty space within a folder) in File Explorer.
Custom Commands: Save your frequently used prompts as custom commands for quick, repeatable actions. Just type #save after a successful prompt, or #commandname to run a saved command.
Smart Script Generation & Fixing: TasCat writes Python scripts to execute your requests and can even try to fix them automatically if they encounter errors.
Safety First: Before TasCat makes significant changes (like deleting or modifying files), it will show you what it plans to do and ask for your permission (this can be configured).
Automatic Python Module Installation: If a generated script needs a special Python library (like for Word documents or images), TasCat will try to install it for you.

🚀 Get Started: Installation
Setting up TasCat is quick and only needs to be done once! Please follow these steps:

Step 1: Install Python 3 
TasCat uses Python to run the AI-generated automation scripts. 

Download Python: Visit the official Python website: https://www.python.org/downloads/
Install: Download the latest Python 3 version and run the installer. Crucially, make sure to check the box that says "Add Python to PATH" during installation. This is very important for TasCat to work correctly.



Step 2: Get Your Google Gemini API Key 
TasCat uses Google's Gemini AI to understand your commands and generate scripts. You'll need a free API key:

Go to Google AI Studio: Open your web browser and navigate to aistudio.google.com. 
Sign In: Log in with your Google account.  You might need to accept terms of service if it's your first time.
Find "Get API Key": On the Google AI Studio page, look for and click the "Get API key" button.  (It's usually in the top right ).

Create New API Key: Click "Create API key in new project" (or choose an existing project if you have one). 
Copy Your Key: Your new Gemini API key will be displayed.  Immediately copy this key and store it somewhere safe. 

You can also watch this video for a guided walkthrough: https://youtu.be/o8iyrtQyrZM 



Step 3: Run TasCat to Install Integration
Run the TasCat executable. (You might need to run it as an administrator for the first-time setup to allow it to integrate with your right-click menu).
TasCat will prompt you to enter your license key (if you've purchased TasCat) and your Gemini API key. Paste them in when asked. 
That's it! TasCat will set up the right-click menu integration. You won't need to enter these keys again unless you uninstall the app and choose to remove them. 


🚀 How to Use TasCat:
Once installed:

Open File Explorer.
Right-click on any folder, or right-click in the empty space within a folder.
Select "Show more options" (on Windows 11) or directly see "TasCat" (on Windows 10). 
Click "TasCat" to open the TasCat command window for that folder. 
Enter your prompt! For example:
"List all PDF files in this folder."
"Rename all .jpg files to add 'holiday_' at the beginning."
"Create a new text file named 'meeting_notes.txt' with today's date and time."
"Create 100 random text files."
For quick command functionality, open TasCat and type #help for more information.
